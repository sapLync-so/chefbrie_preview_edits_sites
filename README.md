# Chef Brie — client preview (proposed site edits)

This repository is a **public preview snapshot** of proposed visual and UX updates for [Chef Brie](https://chefbrie.llc). It is **not** the production site or the private development repository.

## What you are looking at

- Next.js demo of the revamp concept (menus, services pages, gallery, testimonials).
- **Demo concept** banner and **demo booking** flow — not connected to live scheduling or payments.
- **Contact inquiries are disabled** in this preview (no data is sent or stored).
- **Powered by SapLync** footer link is intentional.

## Deploy on Vercel

1. Import this GitHub repository in Vercel (framework preset: **Next.js**).
2. Build command: `npm run build` (default).
3. Output directory: Next.js default (Vercel handles `.next` automatically).
4. No environment variables are required for build or browsing the preview.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
